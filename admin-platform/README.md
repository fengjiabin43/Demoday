# 识光 Insight 独立管理后台 Demo

本项目与 AI 学习搭子独立，不修改产品代码或增加产品入口。

在本目录运行 `npm install`（当前工作区可复用父目录已有依赖），然后 `npm start`。

本地访问 http://127.0.0.1:5180/ 。在线演示：https://fengjiabin43.github.io/Demoday/admin/ 。

包含数据概览、用户分析、转化与流失、行为路径、反馈管理、数据接入。全局支持近 7/14/28 天、截止日期、来源渠道和学习路线筛选；流失人数可下钻用户，用户详情展示行为时间线与反馈；反馈支持状态、负责人、优先级和处理备注修改，保存在当前浏览器；支持 CSV 导出和校验后的 JSON 导入。

默认是明确标注的演示数据，覆盖截至昨日的 28 天，并非线上结果。真实数据需在「数据接入」下载模板后导入；演示与导入数据隔离保存。未自动接入产品埋点、服务器数据库、账户与权限，不把退出会话直接认定为永久流失。

指标口径和文件字段可在网站「数据接入」中查看。修改源码后重启服务会重新构建。`npm run check` 运行 TypeScript 检查，`npm run build` 产出静态文件到 dist。
