## 执行目标

在现有工程基础上尽快交付可实际体验的移动端优先网页：用户领养专属学习Agent，通过趣味短视频与碎片关卡学习，由Agent维护记忆和知识结构，并在工作台查看、管理和使用学习成果。

先检查工程现状和适用的AGENTS.md；保留已有实现，避免重复搭建。不要再次讨论已经确认的定位，也不要只交付页面设计或开发计划。

## 开发优先级

1. 尽快启动工程并建立可访问的本地预览；在研发会话报告真实地址和启动方式。
2. 打通最短完整路径：观看一段真实短视频、作答、解释、保存学习证据、更新知识视图、返回后接续。
3. 接入Agent领养、常驻交互、上下文帮助、经验去重、章节检查与形态解锁。学习记录、奖励和工作台必须使用同一状态来源。
4. 完成工作台：今日队列、可点击知识地图、证据详情、Agent记忆管理、等级与形态、整理动态。
5. 完成学以致用：填写真实场景、按问题类型生成判断卡、编辑、保存、复制和导出。来源和待确认项必须保留。
6. 补齐三条短视频、十二道题、八个知识节点、三条起始路线和四阶段形态，按PRD验收。

阶段交付允许先完成一个章节再扩展，但不能把阶段版本宣称为全部P0完成。

## 关键体验要求

- 用户学习时间不可预测，每步可以暂停；无需固定长时段。
- 视频真实可播放，有时间轴、字幕、暂停、拖动和恢复。不能用封面加播放按钮替代。
- 学习Agent有明确点击入口，能解释当前内容、推荐理由和知识关系；保存目标、进度和带来源的学习证据。
- 有提示作答、独立作答、重复题记录分开；观看或经验不直接等于掌握。
- 六个练习首次通过各20经验，六个检查题首次通过各40经验；重复提交不重复奖励。
- 等级2为80经验且一个章节完成，等级3为160经验且两个章节完成，等级4为240经验且三个章节完成。每章两个检查题都通过才完成该章。
- 工作台知识点能追溯到视频、题目、证据和来源；不是只显示静态图或虚构能力分数。
- 用户可修正目标、调整路线、查看和删除记忆；删除证据后重算相关知识状态，奖励去重记录独立保存。
- Agent成长体现外观与个性化积累，基础学习能力从首次使用即可用。

## 实现取舍

采用合适的技术框架与本地持久化即可，无需先开发登录、云同步、商城或社交合养。先完成可靠的本地学习和规划逻辑。

有可用模型服务时接入上下文解释；没有服务时使用审核解释、提示、FAQ与应用模板，明确说明帮助范围。不能伪装模型调用、全网实时采集或真实系统检测。开放模型接入不得阻塞已有核心路径。

视频优先用统一动画模板制作三条原创成片，内容与分镜见PRD；音频可按制作资源安排，字幕必须可用。成片是最终验收依赖。
