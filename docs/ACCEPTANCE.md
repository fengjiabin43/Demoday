# 前端验收报告

日期：2026-10-12。规格来源：PRD.md、DEV_HANDOFF.md。交付为可操作的完整前端模拟版；真实后端和模型按用户要求暂不接入。

## 预览与启动

- 开发预览：http://127.0.0.1:5173/，命令 `npm run dev`。
- 生产预览：http://127.0.0.1:4173/，命令 `npm run build` 后 `npm run preview`。
- 前端：React + TypeScript，Vite 开发服务，esbuild 生产构建；后端规划为 NestJS + PostgreSQL。
- 数据：当前浏览器 localStorage，使用一个模拟 API 事务更新所有页面。验收浏览器使用隔离上下文，不向用户浏览器填充演示进度。

`npm run test:resilience`（先启动生产预览）：4 项异常验证通过。报告见 `test-results/resilience-results.json`。

1. 页面隐藏事件立即暂停视频，不继续累计活动时间。
2. 断网后重新加载生产页面，缓存的真实 MP4 继续播放。
3. 离线标准题可以提交，保存证据和奖励。
4. 禁用未缓存视频请求后显示重试、完整图文；图文阅读事件不计为视频。

## 仍未实现与边界

- 未实现真实后端、登录、云同步、开放模型、自动全网内容更新。这是本次已约定的前端模拟边界，不以模拟结果声称上线效果。
- 三条成片无配音，使用原创动画与可切换字幕；不是封面加播放按钮。
- 离线依赖首次联网缓存完成。首次从未访问过的设备不能凭空加载网页，未缓存内容须联网。
- 判断卡是模板建议，未检测用户真实问答系统；用户自填结论需实际材料验证。
- 学习时间是估算，未宣称精确衡量学习投入；未开展真实用户留存、迁移和学习效果研究。
- 原执行单的两小时安排是预算，不作为本次已取得性能或学习效果指标。
